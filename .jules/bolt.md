## 2025-05-22 - [Lazy State Initialization & Code Splitting]
**Learning:** Initializing state from `localStorage` inside a `useEffect` triggers a redundant re-render on mount and can cause a flash of unstyled content. Using a lazy state initializer (`useState(() => ... )`) is more efficient and satisfies the `react-hooks/set-state-in-effect` ESLint rule. Additionally, when using `framer-motion`'s `AnimatePresence` with `React.lazy` routes, the `location` prop must be passed to the `Routes` component to ensure exit animations work correctly during asynchronous chunk loading.
**Action:** Always prefer lazy initializers for state derived from synchronous I/O like `localStorage`. Ensure `AnimatePresence` has the current `location` when implementing route-based code splitting.

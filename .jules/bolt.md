## 2026-05-04 - [Route-based Code Splitting & Lazy State Initialization]
**Learning:** In a React application with 'framer-motion' animations on route transitions, implementing 'React.lazy' requires passing the 'location' object to the 'Routes' component within 'AnimatePresence' to ensure exit animations continue to function correctly. Additionally, lazy state initialization in components that read from 'localStorage' (like theme toggles) prevents a double-render on mount and avoids hydration-like mismatches or flashing.
**Action:** Always use 'lazy' initialization for 'useState' when the initial value depends on expensive or synchronous I/O like 'localStorage.getItem()'. When combining 'lazy' routes with 'AnimatePresence', ensure the 'location' prop is correctly wired to the 'Routes' component.

## 2025-05-15 - React State Initialization and Route Splitting
**Learning:** Initializing state from localStorage inside a `useEffect` triggers a second render immediately after mount, which can cause layout shifts or theme flashing. Using a lazy initializer function in `useState` (e.g., `useState(() => localStorage.getItem('theme'))`) executes only once during the initial render, making it more efficient and cleaner for ESLint. Additionally, when using `React.lazy` with `framer-motion`, the `location` prop must be passed to `Routes` to maintain exit animations during route transitions.
**Action:** Always prefer lazy state initializers for values derived from `localStorage` or heavy computations. When implementing code splitting, ensure the routing configuration supports animation requirements.

## 2025-05-14 - Route-based Code Splitting & Lazy Initialization
**Learning:** In a React application with multiple distinct pages, the initial bundle size can be significantly reduced by using `React.lazy()` and `Suspense` for route components. Even in relatively small projects, this ensures that the user only downloads the code necessary for the initial view, improving the Largest Contentful Paint (LCP) and Time to Interactive (TTI). Additionally, using lazy initialization for `useState` when reading from `localStorage` prevents redundant and relatively expensive synchronous I/O operations on subsequent re-renders.
**Action:** Always evaluate route-based code splitting for any application with more than 2-3 pages. Always use lazy `useState` initializers (e.g., `useState(() => ... )`) for values derived from `localStorage` or other side-effect-heavy sources.
